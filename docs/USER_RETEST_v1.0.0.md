## 5. 出问题了怎么反馈（越具体越好）

把这三样发回来：

1. 程序**"状态 / 日志"框的全文**（已脱敏：Cookie / Authorization 一律不出现在日志里）；
2. 一句话说明：哪个场景（A/B/C/D）、卡在第几步、弹窗标题写的什么；
3. 如果方便：你所在网络的大致类型（家宽 / 公司 / 机房 / 手机热点）—— 用于判断是不是风控环境差异。

自检命令（可选，你很熟命令行的话）：

```bat
:: cmd 里这样跑（会等它结束）
KHDownloader.exe --selftest-transport --selftest-out "%USERPROFILE%\Desktop\khd_selftest.txt"
```

```powershell
# PowerShell 里要用 Start-Process -Wait，否则它不阻塞（GUI 程序不抢控制台）
Start-Process -FilePath .\KHDownloader.exe -Wait -PassThru -ArgumentList `
  '--selftest-transport','--selftest-out',"$env:USERPROFILE\Desktop\khd_selftest.txt"
# 输出里的 ExitCode = 0 就是通过
```

它会自己连一次站点，把 `PASS/FAIL`、状态码、字符数、曲目数、以及"有没有升级"写进那个 txt，
退出码 `0` = 通过。**不下载任何文件**，不会弹窗。
执行环境刚刚跑过一次（2026-10-15，直接从交付目录）：`ExitCode 0`、`RESULT: PASS`、
`curl_cffi: True`、`200 / 82918 字符 / 30 首`、**无需升级**。

## 已知限制（如实说）

- 站点风控在变、出口网络也在变，**没有人能承诺"永远一层就过"**；
  程序会逐级升级并在日志里说明，四层都没过时会说清是哪几层试过了。
- L2 / L3 需要源码版装了 Playwright；**EXE 版可用的是 L1 与 L4**，
  其中 L4 需要你机器上有 Chrome 或 Edge（通常都有）。
- L4 使用**一次性临时配置目录**跑本机浏览器：不读你的浏览器配置、Cookie、书签、历史。
- 本轮**不涉及**也不修改：Windows 防火墙规则、系统代理、安全软件设置
  （你机器上这三项本来就是原样未动）。
- 本 EXE **没有数字签名**，首次运行可能弹"Windows 已保护你的电脑"
  → 点「更多信息」→「仍要运行」。
- 执行环境里已完成的验证：源码 179 项测试全过、过校验三组对照 14/14 通过、
  真站 30 首端到端通过、**冻包 EXE 自检 PASS**（`curl_cffi: True`，无需升级即取到页面）。
  剩下的就是**你自己手点一遍**。
